# 历史资料归档

此目录保存**历史设计快照**、过往讨论、实验提示词与已被迭代替代的工具方案。归档意味着「可供追溯」，**不代表代码当前行为**，也不代表文档内的 TODO 仍未完成。

- `legacy/`：2026 年 6 月之前及同期的交接材料、旧总览、旧路线图、上下文工程/Skill/Task MVP 计划。
- `tool-design/`：历史逐工具设计；工具的现行契约以 `tools/` 源码、`tests/test_protocol_compliance.py` 和 [协议说明](../通用工具响应协议.md) 为依据。
- `enhancement-plan.md` 与 `fixed_update.md`：更早期的实施计划、状态和缺陷追踪。

旧文档里的路径、测试数量、API 结构和安全假设可能已经失效；归档文档中的相对链接可能保留原目录结构时的写法。需要实施时应先确认代码及测试，不要直接照搬。

如需要了解当前架构，请返回 [docs/ARCHITECTURE.md](../ARCHITECTURE.md)。
